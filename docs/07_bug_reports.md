# Баг-репорты

## BUG-01: Попытка создать дубликат файла

**Серьёзность:** средняя
**Приоритет:** средний
**Статус:** закрыт (не воспроизводится)

**Шаги воспроизведения:**
1. Создать файл `/dup.txt` с содержимым `"a"`.
2. Повторно создать файл `/dup.txt` с содержимым `"b"`.

**Ожидаемый результат:** второй вызов возвращает `-1`.
**Фактический результат:** второй вызов возвращает `-1`.
**Причина:** в `fs.create_file` выполняется проверка на существование.
**Решение:** дефект не обнаружен, поведение корректное.

## BUG-02: Пользователь не может удалить чужой файл

**Серьёзность:** высокая
**Приоритет:** высокий
**Статус:** закрыт (не воспроизводится)

**Шаги воспроизведения:**
1. Создать файл `/check.txt` от имени `admin`.
2. Вызвать `sys_delete_file('/check.txt', 'user')`.

**Ожидаемый результат:** `False` и запись `DENIED` в `syscalls_log`.
**Фактический результат:** `False`, статус `DENIED`.
**Причина:** `check_permission('user', 'delete_file', 'admin')` → `False`.
**Решение:** дефект не обнаружен, права разграничены корректно.

## BUG-03: Превышение лимита памяти не создаёт процесс

**Серьёзность:** средняя
**Приоритет:** средний
**Статус:** закрыт (не воспроизводится)

**Шаги воспроизведения:**
1. Вызвать `scheduler.create_process('huge', 'admin', 5000)`.

**Ожидаемый результат:** `pid == -1`, память ядра не изменилась.
**Фактический результат:** `pid == -1`, `memory_used == 0`.
**Причина:** `kernel.allocate_memory(5000)` → `False`.
**Решение:** дефект не обнаружен.
