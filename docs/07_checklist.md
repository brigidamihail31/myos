# Чек-лист функциональности ОС

## Оболочка
- [ ] Команда `help` выводит список команд.
- [ ] Команда `echo` возвращает переданное сообщение.
- [ ] Команда `whoami` возвращает текущего пользователя.
- [ ] Команда `login` запрашивает логин и пароль.
- [ ] Команда `mem` показывает состояние памяти.
- [ ] Команда `logs` выводит записи журнала.
- [ ] Команда `exit` завершает работу.

## Файлы
- [ ] Команда `create` создаёт файл.
- [ ] Команда `cat` читает файл.
- [ ] Команда `ls` выводит список файлов.
- [ ] Команда `delete` удаляет файл.
- [ ] Повторное создание файла с тем же путём возвращает ошибку.
- [ ] Обычный пользователь не может удалить чужой файл.

## Процессы
- [ ] Команда `run` запускает процесс.
- [ ] Команда `ps` выводит список процессов.
- [ ] Команда `kill` завершает процесс.
- [ ] После завершения процесса память освобождается.
- [ ] Обычный пользователь не может завершить чужой процесс.

## Пользователи
- [ ] Команда `register` создаёт пользователя.
- [ ] Слабый пароль не принимается.
- [ ] Команда `logout` завершает сессию.

## База данных
- [ ] Таблица `users` заполняется.
- [ ] Таблица `files` заполняется.
- [ ] Таблица `processes` заполняется.
- [ ] Таблица `syscalls_log` заполняется.
- [ ] Таблица `memory_state` обновляется.
- [ ] Схема совместима с текущим кодом (`pid`, `memory_used`, `limit_`).
