# 02. Архитектура учебной ОС и API ядра

## 1. Список модулей ОС

| Модуль | Назначение |
|---|---|
| `shell.py`      | Командная оболочка: принимает команды пользователя, вызывает системные вызовы, отображает результат |
| `syscalls.py`   | Публичный API ядра: набор системных вызовов, функция `log_syscall`, обёртка `_timed` |
| `kernel.py`     | Ядро: инициализация подсистем, проксирующие методы к scheduler / memory / fs / auth |
| `scheduler.py`  | Подсистема планирования процессов: создание, состояния, выбор процесса, завершение |
| `memory.py`     | Подсистема управления памятью: выделение и освобождение памяти процессам |
| `fs.py`         | Файловая система поверх SQLite: создание, чтение, удаление, список файлов |
| `auth.py`       | Подсистема безопасности: аутентификация (SHA-256) и авторизация по ролям |
| `db.py`         | Слой доступа к SQLite: соединение, инициализация таблиц, CRUD |
| `config.py`     | Конфигурация: пути, лимиты (`MAX_PROCESSES`, `MAX_SYSCALL_TIME_MS`), алгоритм хэша |
