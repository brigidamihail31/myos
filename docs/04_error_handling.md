# 04. Отчёт по обработке ошибок

## 1. sys_login с несуществующим пользователем
- **Результат:** `False`
- **Причина:** пользователь не найден в таблице `users`.
- **Лог:** `sys_login | nobody | guest | DENIED`.

## 2. Регистрация с существующим логином
- **Результат:** `None`
- **Причина:** проверка через `execute_select` перед вставкой.
- **Лог:** `sys_register | login=admin | admin | DENIED`.

## 3. Пустой пароль
- **Результат:** вход выполняется.
- **Замечание:** в реальной ОС следовало бы запретить пустые пароли.
  Добавьте в `register_user()` проверку `len(password) < 4`.

## 4. Превышение лимита памяти
- **Результат:** `False`
- **Причина:** `allocate_memory` проверяет `memory_used + size > memory_limit`.
- **Лог:** в `syscalls_log` статус `SLOW`/`OK` в зависимости от времени.

## 5. Удаление чужого файла обычным пользователем
- **Результат:** `False`, статус `DENIED` в `syscalls_log`.
- **Причина:** `check_permission("user", "delete_file", "admin")` → `False`.
